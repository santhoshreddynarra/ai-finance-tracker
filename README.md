# AI Finance Tracker

A full-stack web application built to help users manage their personal finances. This project provides a simple way to track income and expenses, set monthly budgets, and view spending patterns. It integrates with the OpenAI API to offer basic financial insights based on user data.

## Features

- User Authentication: Secure login and registration using JWT and bcrypt.
- Transaction Management: Add, edit, delete, and filter income and expense records.
- Budget Management: Set and monitor monthly spending limits for different categories.
- Dashboard Analytics: View a summary of total balance, recent transactions, and spending breakdowns.
- AI Insights: Receive personalized financial suggestions generated by OpenAI based on recent activity.
- Expense Prediction: Estimate upcoming expenses by analyzing historical transaction data.
- Monthly Reports: Generate automated summaries of monthly financial activity.
- PDF Export: Download monthly reports as formatted PDF files.

## Project Structure

client/
Contains the React frontend, including components, pages, Redux slices, and API services.

server/
Contains the Node.js backend API.

server/models/
Defines the Mongoose database schemas for users, transactions, and budgets.

server/controllers/
Contains the business logic for handling incoming API requests.

server/routes/
Maps API endpoints to their respective controllers.

server/middleware/
Handles request interception for authentication and global error management.

## Application Flow

User Login -> Authentication -> Dashboard -> Transactions/Budget -> Analytics -> AI Insights

## Installation

Clone the repository:
```bash
git clone https://github.com/santhoshreddynarra/ai-finance-tracker.git
cd ai-finance-tracker
```

Install backend dependencies:
```bash
cd server
npm install
```

Install frontend dependencies:
```bash
cd ../client
npm install
```

Create `.env` files in both the `server` and `client` directories using the examples below.

Start the backend server:
```bash
cd server
npm run dev
```

Start the frontend server:
```bash
cd ../client
npm run dev
```

## Environment Variables

server/.env
```env
PORT=5000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/database_name
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRE=7d
OPENAI_API_KEY=your_openai_api_key
FRONTEND_URL=http://localhost:5173
```

client/.env
```env
VITE_API_URL=http://localhost:5000/api
```

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | /api/auth/signup | Register a new user |
| POST | /api/auth/login | Authenticate a user |
| GET | /api/transactions | Get all user transactions |
| POST | /api/transactions | Create a new transaction |
| PUT | /api/transactions/:id | Update an existing transaction |
| DELETE | /api/transactions/:id | Delete a transaction |
| GET | /api/budgets | Get all user budgets |
| POST | /api/budgets | Create a new budget |
| PUT | /api/budgets/:id | Update a budget |
| DELETE | /api/budgets/:id | Delete a budget |
| POST | /api/ai/insights | Generate AI spending insights |
| GET | /api/reports/pdf | Download a monthly PDF report |
